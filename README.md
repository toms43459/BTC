# BTC

## 支撐阻力指標（TradingView Pine Script v6）

檔案：[`support_resistance.pine`](support_resistance.pine)

依「前高前低 + 成交量確認 + 互換原理」自動畫出支撐 / 壓力，並在K棒上用箭頭標示進出場訊號。
不綁定商品，**任何幣種、任何週期都可以開**。

### 使用方式

1. TradingView 下方開啟「Pine 編輯器」
2. 把 `support_resistance.pine` 全部內容貼上，覆蓋原本內容
3. 按「儲存」→「加到圖表」

### 名稱

| 名稱 | 意思 |
| --- | --- |
| **強支撐** | 價格下方、被前高 / 前低觸碰 ≥ 3 次（可調）的價位 |
| **支撐** | 價格下方的價位 |
| **強壓力** | 價格上方、被前高 / 前低觸碰 ≥ 3 次（可調）的價位 |
| **壓力** | 價格上方的價位 |

- 壓力被收盤突破後會直接改名為「支撐」，支撐被收盤跌破後改名為「壓力」（互換原理，不另外標「互換支撐」）。
- 設定裡可把「壓力」改成「阻力」。
- 強的價位用實線、較粗；一般價位用虛線。
- 標籤滑鼠移上去可看觸碰次數與區間範圍。

### 訊號（箭頭）

| 箭頭 | 訊號 | 條件 |
| --- | --- | --- |
| ▲ 綠 | **帶量突破** | 收盤價站上壓力區，成交量 ≥ 均量 × 1.5，且為實體紅K（實體 ≥ 整根一半） |
| ▲ 綠 | **支撐反彈** | 由上方回檔到支撐區，收盤守住支撐，並出現止跌K棒（長下影線 / 紅K吞噬 / 量縮止穩） |
| ▲ 綠 | **假跌破** | 帶量跌破後 3 根K棒內，收盤又站回線上 |
| ▼ 紅 | **帶量跌破** | 收盤價跌破支撐區，帶量且為實體黑K |
| ▼ 紅 | **壓力回落** | 由下方反彈到壓力區，收盤未站上，並出現止漲K棒（長上影線 / 黑K吞噬 / 量縮止漲） |
| ▼ 紅 | **假突破** | 帶量突破後 3 根K棒內，收盤又跌回線下 |

- 多方訊號在K棒下方，空方訊號在K棒上方；同一根K棒有多個訊號會合併在同一個標籤。
- 預設 K棒收盤後才標示，不會盤中出現又消失。
- 每種訊號都可設定 TradingView 警報（建立警報 → 條件選「支撐阻力」→ 選訊號）。
- 不畫 TP / SL。

### 主要參數

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| 前高 / 前低 左右K棒數 | 10 | 越大價位越少、越重要 |
| 強支撐 / 強壓力 觸碰次數 | 3 | 達到此次數名稱加「強」 |
| 同一價位合併距離 | 1.0 ATR | 距離內的前高前低算同一價位 |
| 區間寬度 | 0.3 ATR | 收盤超出區間才算有效突破 / 跌破 |
| 上下各顯示幾條 | 4 | 只顯示離現價最近的幾條 |
| 帶量倍數 | 1.5 | 成交量 ≥ 均量 × 此倍數才算帶量 |
| 假突破判定K棒數 | 3 | 突破後幾根內跌回算假突破 |
| 價位 / 訊號文字大小 | 大 | 小 / 中 / 大 / 特大 |

顏色、文字大小、是否顯示價格與區間底色都可在「設定 → 輸入」調整。

## 趨勢訊號指標 + 回測策略（TradingView Pine Script v6）

| 檔案 | 用途 |
| --- | --- |
| [`trend_signals.pine`](trend_signals.pine) | 指標：在圖上顯示 ▲ 做多 / ▼ 做空、停損停利線、右上角表格、長線背景色、警報 |
| [`trend_strategy.pine`](trend_strategy.pine) | 策略：同一套規則，用 TradingView「策略測試器」回測 |

兩個檔案的支撐 / 壓力判定都沿用 `support_resistance.pine`（前高前低、觸碰次數 → 強支撐 / 強壓力、帶量突破、支撐反彈…）。
設計給 **15 分或 1 小時圖**。所有數字參數都可以在「設定 → 輸入」調整，兩個檔案的參數名稱與預設值相同。

### 安裝

1. TradingView 下方開啟「Pine 編輯器」
2. 新增指標 → 把 `trend_signals.pine` 全部內容貼上 → 「儲存」→「加到圖表」
3. 再新增一個 → 貼上 `trend_strategy.pine` → 「儲存」→「加到圖表」（要回測時才需要）

### 規則

**一、長線趨勢（半年方向）**：不論圖表週期，都讀週線與日線**已收盤**的K棒（lookahead 關閉，不用未來資料、不重繪）

| # | 條件 |
| --- | --- |
| 1 | 週線收盤 > 週線 EMA50 |
| 2 | 週線 EMA50 比 4 週前高（斜率向上） |
| 3 | 日線 EMA50 > 日線 EMA200 |
| 4 | 週線 RSI(14) > 50 |

- 成立 ≥ 3 個 = **長線偏多**（背景淡綠）；≤ 1 個 = **長線偏空**（背景淡紅）；其他 = **中性**（不上色）
- 高週期歷史不夠、算不出 EMA200 等數值時，表格顯示「資料不足」，並視為中性

**二、短線訊號**：以下條件**全部**成立才出訊號（做空全部反過來）

| 做多條件 | 做空條件 |
| --- | --- |
| 長線不是偏空，且 4 小時 EMA50 > EMA200 | 長線不是偏多，且 4 小時 EMA50 < EMA200 |
| 最近 5 根K棒內碰到 EMA21 附近（0.5 ATR 內）或碰到支撐，本根收盤站上 EMA21 | 最近 5 根K棒內碰到 EMA21 附近或碰到壓力，本根收盤跌破 EMA21 |
| RSI(14) 由下往上穿越 50 | RSI(14) 由上往下穿越 50 |
| 成交量 > 20 根均量 × 1.3 | 同左 |
| ADX(14) > 20 | 同左 |
| 上方最近的強壓力距離 > 1.5 ATR（太近不做） | 下方最近的強支撐距離 > 1.5 ATR |
| 通過盤整過濾（見下方） | 同左 |

**盤整過濾**（預設開啟，設定「④ 盤整過濾」可分別關閉、調參數）：

- **ADX 正在下降**時不出訊號：ADX 低於 1 根K棒前（可調）= 趨勢轉弱
- 收盤價在**最近 50 根K棒高低區間的中間 50%**（25%～75% 的位置）時不出訊號，只在靠近區間上緣或下緣時才出訊號

額外規則：

- 長線**中性**時，只在 4 小時 ADX > 25（趨勢很明確）時才出訊號
- 出一個訊號後，10 根K棒內不再出同方向訊號
- 一次只持有一筆：持倉中不出新訊號，出場後才會再出
- 同一天（預設 UTC+8，可改）**連虧 2 筆**就停止出訊號，隔天歸零；中間只要賺一筆，連虧就重新計算
- **連虧暫停**（預設開啟）：不分日期，**連續虧損 3 筆**後暫停 20 根K棒不出訊號；暫停結束後連續虧損重新計算。暫停期間背景顯示灰色
- 訊號K棒同時出現 `support_resistance.pine` 的「帶量突破」或「支撐反彈」（做空：「帶量跌破」或「壓力回落」）→ 標籤顯示「▲ 做多（強）」/「▼ 做空（強）」
- 訊號都在K棒**收盤後**才確認，不會盤中出現又消失

**三、風險管理**

| 項目 | 規則 |
| --- | --- |
| 停損 | 1.5 × ATR(14) 與「最近 10 根K棒波段低點（做空：高點）外側 0.1 ATR」取**較近**者，但距離不小於 1 ATR |
| 停利 1 | 1.5R，出一半 |
| 停利 2 | 3R（預設）；可改成「剩餘部位用 ATR 移動停損」或「兩者皆用，先到先出」 |
| 移動停損 | 停利 1 之後啟動：持倉期間最高價（做空：最低價）回落 2 ATR，只往有利方向移動 |
| 每筆風險 | 本金的 2% |
| 建議倉位 | 本金 × 風險% ÷ 停損距離 |
| 建議槓桿 | 倉位價值 ÷ 本金，上限 5 倍；超過上限時倉位縮到 5 倍，實際風險會小於設定（表格會顯示實際風險%） |

R = 進場價到停損的距離。例：進場 100、停損 98 → 1R = 2，停利 1 = 103，停利 2 = 106。

### 指標畫面（trend_signals.pine）

- **K棒標籤**：「▲ 做多」在K棒下方、「▼ 做空」在K棒上方；滑鼠移上去看進場、停損、停利、倉位、槓桿
- **線段**：訊號出現時畫出進場（灰點線）、停損（紅）、停利 1（綠虛線）、停利 2（綠實線），持倉期間一直延伸到出場那根K棒；移動停損另外用紅色階梯線顯示
- **出場結果**：每筆出場時標出「停損 -1.00R」「停利2 +2.25R」等（可關閉）
- **背景色**：長線偏多淡綠、偏空淡紅、中性不上色
- **支撐 / 壓力**：上下各畫最近 3 條（可關閉、可調條數）
- **右上角表格**：

| 欄位 | 內容 |
| --- | --- |
| 長線（半年） | 偏多 / 中性 / 偏空，與 4 個條件成立幾個 |
| 週線趨勢 | 收盤是否在 EMA50 上、EMA50 方向、RSI |
| 日線趨勢 | EMA50 與 EMA200 多空排列 |
| 4 小時趨勢 | EMA50 / EMA200 多空、ADX（> 25 標「明確」） |
| 盤整過濾 | 通過 / 盤整中，以及 ADX 上升或下降、價格在近 50 根區間的位置（0% = 最低、100% = 最高） |
| 今日偏向 | 多 / 空 / 觀望（= 目前只允許哪個方向的訊號；今日連虧停止或連虧暫停時顯示觀望，並顯示暫停剩幾根K棒） |
| 連虧 | 今日連虧幾筆 / 上限、連續虧損幾筆 / 暫停門檻、是否暫停中 |
| 目前訊號 | 持倉中的方向，或「無（上一筆：…）」 |
| 進場價、停損、停利 1、停利 2 | 目前這筆（空手時顯示上一筆，並註明「上一筆」） |
| 建議倉位 / 建議槓桿 | 依「本金」輸入計算，含實際風險% |

> 指標的停損停利、連虧是用K棒高低點模擬（同一根K棒同時碰到停損與停利時，用 TradingView 回測相同的路徑假設：開盤較接近高點就先走高點）。實際成交以策略回測為準。

### 警報

建立警報 → 條件選「趨勢訊號」，然後選其中一種：

- 「做多訊號」/「做空訊號」：`alertcondition` 警報，各自獨立
- 「任何 alert() 函式呼叫」：做多、做空都會通知，訊息裡附上進場、停損、停利、倉位、槓桿

### 回測（trend_strategy.pine）

策略的固定設定（在程式碼 `strategy()` 裡，也可以在「設定 → 屬性」修改）：

| 項目 | 值 |
| --- | --- |
| 初始資金 | 10000 USDT |
| 手續費 | 每邊 0.05% |
| 滑價 | 2 tick |
| 保證金 | 多空各 10%（回測最多允許 10 倍；實際槓桿由輸入「槓桿上限」控制，預設 5 倍） |
| 進場 | 訊號K棒收盤確認，下一根K棒開盤市價進場 |
| 倉位 | 目前權益 × 風險% ÷ 停損距離（隨盈虧複利），槓桿超過上限就縮倉 |

**怎麼用策略測試器看結果：**

1. 開 15 分或 1 小時的K線圖（例如 `BINANCE:BTCUSDT.P` 或 `BINANCE:BTCUSDT`），把 `trend_strategy.pine` 加到圖表
2. 畫面下方點「**策略測試器**」（Strategy Tester）分頁，選「趨勢策略」
3. 看這幾個地方：
   - **概覽**（Overview）：淨利、最大回撤、勝率、獲利因子、總交易次數，以及權益曲線
   - **績效摘要**（Performance Summary）：多單 / 空單分開的績效、平均每筆盈虧、最大連續虧損、手續費總額
   - **交易清單**（List of Trades）：每一筆的進出場時間、價格、出場原因。註解會顯示「▲ 做多 / ▲ 做多（強）」與「停利1 / 停利2 / 停損 / 移動停損」
4. 圖上會顯示每筆的進出場箭頭，以及持倉中的停損（紅）、停利 1 / 停利 2（綠）線
5. 調參數：點策略名稱旁的齒輪 →「輸入」改規則參數、「屬性」改資金 / 手續費 / 滑價 / 保證金，改完策略測試器會立刻重算

**回測小提醒：**

- 一筆交易會在交易清單出現 2 列（停利 1 出一半 + 剩下的一半），算「連虧」時是以整筆的淨損益判斷
- 回測期間 = 圖表載入的K棒數量。15 分圖的歷史比較短，想看更長時間可以：用 1 小時圖、或用付費方案的「深度回測」（Deep Backtesting）選日期範圍
- 想讓K棒內的停損停利成交順序更精確，可在「屬性」勾選「使用K棒放大器」（Bar Magnifier，付費方案）
- 停損很近時（例如 15 分圖只有 0.3%），用 2% 風險算出的倉位會超過 5 倍，會被槓桿上限縮倉，實際每筆風險會低於 2%
- 想看盤整過濾、連虧暫停的效果，可以在「輸入」把它們關掉再打開，比較策略測試器的交易次數、勝率與最大回撤
- 長線趨勢需要大約 1 年的週線、200 天的日線才算得出來；資料不足時視為中性，只有 4 小時 ADX > 25 才會出訊號
- 指標與策略規則相同，但策略是「下一根開盤」成交並扣手續費與滑價，所以結果會和指標上標的 R 值略有差異
- 回測結果不代表未來績效，實盤前請先用小資金或模擬盤驗證
